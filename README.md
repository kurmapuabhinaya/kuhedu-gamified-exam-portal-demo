# KUHEDU Gamified Exam Portal

This project is a frontend prototype of a gamified learning platform developed during a web development internship. The portal aims to make exam preparation more interactive by allowing teachers to create quizzes and students to practice them.

## Technologies Used
- Angular
- HTML
- CSS
- TypeScript

## Modules Implemented (30% Completion)
- Login Authentication System
- Dashboard Interface
- Create Quiz Module
- Add Question Module
- Practice Quiz Viewer

## System Workflow
Login → Dashboard → Create Quiz → Add Question → Practice Quiz

## Project Description
The KUHEDU Gamified Exam Portal is designed to improve student engagement through quiz-based learning. Teachers can create quizzes and manage questions, while students can attempt quizzes and test their knowledge.
